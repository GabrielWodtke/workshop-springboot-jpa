# Como executar o projeto

## Back end
Pré-requisitos: Java 17

## Implantação em Produção

Banco de dados: H2

```bash
# clonar repositório
git clone https://github.com/GabrielWodtke/workshop-springboot-jpa.git

# entrar na pasta do projeto back end
cd backend

# executar o projeto
./mvnw spring-boot:run
```
